# ggplo2 demo

ggplo2 demo

## Usage

``` r
demo_number(x, scale_name, ...)
```

## Arguments

- x:

  a numeric

- scale_name:

  scale name

- ...:

  further arguments to be passed to the scale

## Examples

``` r
demo_number(c(32, 212), scale_name = "number_locale")
#> scale_x_number_locale()
```
