# Locales

A dataset containing specification of formatting styles to label
numbers, percentages and currencies for 574 locales based on CLDR
(Common Locale Data Repository) data provided by the
[i18n](https://rich-iannone.github.io/i18n/) package.

## Usage

``` r
locales
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 764
rows and 46 columns.
