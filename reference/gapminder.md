# Gapminder Dataset

A dataset containing data on GDP per capita, life expectancy and
population size of 183 countries for 1800 to 2015

## Usage

``` r
gapminder

gapminder15
```

## Format

A data frame with 14,823 rows and 7 variables:

- country:

  country name

- code:

  country code

- region:

  world region

- year:

  year

- life_exp:

  life expectancy at birth, in years

- gdp_per_cap:

  GDP per capita, in dollars PPP

- pop:

  population size, in persons

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 183
rows and 7 columns.
