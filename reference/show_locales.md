# Locales

A convenience function which returns a dataframe of available locales
and countries.

## Usage

``` r
show_locales()
```

## Value

a dataframe

## Examples

``` r
show_locales()
#> # A tibble: 764 × 1
#>    locale
#>    <chr> 
#>  1 af    
#>  2 af-NA 
#>  3 af-ZA 
#>  4 agq   
#>  5 agq-CM
#>  6 ak    
#>  7 ak-GH 
#>  8 am    
#>  9 am-ET 
#> 10 ar    
#> # ℹ 754 more rows
```
